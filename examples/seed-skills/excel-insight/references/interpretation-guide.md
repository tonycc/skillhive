# 数据解读方法论

> 写解读前必读。解读的价值在于"数据之外的一句话"，不是复述数字。

## 四个标准视角

### 1. 趋势（随时间怎么变）
- 方向：上升 / 下降 / 波动 / 平稳
- 速率：变化在加速还是放缓
- 拐点：哪个时间点发生了什么

### 2. 对比（谁强谁弱）
- Top / Bottom 是谁，差距多大（倍数或百分比）
- 是否显著高于/低于均值（超过 ±30% 值得点名）

### 3. 占比（结构是否合理）
- 头部集中度：Top 3 占比超过 70% 提示依赖风险
- 长尾：大量小项合计是否可观

### 4. 异常（哪里不对劲）
- 突增/突降的点，先给数据事实，再提示用户确认业务原因
- 空值、零值、口径跳变——**只提示，不猜原因**

## 表达规范

- 每个结论后面跟具体数字：「3 月销售额环比下降 23%（152 万 → 117 万）」
- 禁止无依据归因：「可能因为市场竞争」这类话不写
- 拿不准的写成待确认问题，列在报告末尾
