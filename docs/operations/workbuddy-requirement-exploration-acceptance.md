状态定义：

- `仓库通过`：代码、自动化测试或本地 PostgreSQL 已提供直接证据。
- `部分通过`：仓库侧已完成，仍需真实 WorkBuddy、生产环境或公司流程证据。
- `待外部`：无法仅靠本仓库完成。

## 仓库验证命令

```bash
pnpm db:migrate
pnpm check
pnpm audit --prod
pnpm connector:validate
pnpm connector:build -- https://<获批企业域名>/mcp
pnpm validate:production -- --env-file .env --phase deploy
pnpm smoke:workbuddy
pnpm load:workbuddy
pnpm cleanup:explorations
```

`connector:build` 必须使用获批真实地址；示例地址产物不能提交平台。`cleanup:explorations` 默认是 dry-run，未经审批不得增加 `--execute`。

## 正式上线判定

只有 A01—A20 的“上线前仍需补充”全部关闭，才能判定公开市场连接器已正式上线并允许目标企业全员推广。当前仓库完成不等于 WorkBuddy 审核通过、公开上架、生产部署成功或公司数据政策已批准；市场公开可见和安装也不等于已取得企业数据访问权限。
