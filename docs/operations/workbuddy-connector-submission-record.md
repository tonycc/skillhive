逐项记录：

- 安装后只出现员工专属令牌输入项，不要求地址、JSON 或 SkillHive Web 登录。
- 连接器能发现普通 Skill 检索/读取工具和 7 个探索工具；企业 Skill 助手及需求探索快捷入口可由自然语言和菜单触发。
- 企业 Skill 助手能按名称、简介、分类和标签找到当前员工可见的普通 Skill；不可见或未发布 Skill 不出现在结果中。
- 统一能力检索明确区分 `entryType: skill` 与 `entryType: application`；普通 Skill 检索不返回应用 Skill，需求探索从统一入口和快捷入口都进入同一应用流程。
- 需求探索入口服从服务器锁定的 Grill Me 应用 Skill：按动态决策树询问完整当前 frontier，不限制每轮问题数量。
- 状态检查、开始、阶段保存、查询、正式提交、管理员要求补充、员工读取反馈和重新提交完成闭环。
- 未激活规则不会被通用 Skill 读取旁路；已有探索保持锁定版本。
- 当前激活版本被紧急禁止后，状态检查显示不可写、企业应用目录不再返回需求探索入口，历史内容仍可读取。
- 两个员工对象隔离；令牌吊销、到期和员工停用立即拒绝后续调用。
- revision 冲突、请求重试、服务不可用和内容缺项均给出可恢复且不造成假成功的提示。
- 员工回执不包含管理端登录或免登录详情链接。
